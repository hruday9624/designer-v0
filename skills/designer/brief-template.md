# Intake brief

Fill from what is already known. Ask only for blanks, in one message.

## The five lines (from the PIXELS Guide)

- **Business:** what is sold, in one sentence.
- **Audience:** who buys it, specific ("busy dentists in Texas", not "professionals").
- **Feeling:** three words ("calm, premium, trustworthy").
- **One action:** what a visitor should do ("book a free call"). One only.
- **Proof:** one real result, review or number that can be shown. If none exists, write NONE and
  design without a proof section.

## The extras

- **Mode:** NEW / REDO (polish or rebuild?) / CLONE-LOOK / MOTION / REVIEW / PROMPT
- **Scope:** one page or multi-page; list the pages.
- **References:** sites the user likes, and what exactly they like about each (feel, layout,
  motion, type). If the answer is "that site", extract its DESIGN.md.
- **Brand assets:** logo, existing colours and fonts, photos, existing copy, client voice notes.
- **Voice:** the operator's own page: their own voice notes if any. Client page: ask for the
  client's voice (tone rules, banned words).
- **Stack and hosting:** single file or Next.js; where it will live; domain.
- **Constraints:** deadline, languages, accessibility needs, forms and integrations (where do
  leads go).
- **Real content available:** copy, pricing, FAQs. Anything missing is flagged, not invented.

## Output of intake

Write the filled brief as the first section of `design-log.md` in the site folder, then move to
step 2.
